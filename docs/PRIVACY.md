# 隐私与反馈数据说明

这份说明针对 **OPT Alpha 01 与本 GitHub 公共反馈仓库**。

Alpha 阶段的原则是：尽可能本地优先，同时清楚区分“产品在本机运行产生的信息”和“用户主动提交到公开 GitHub 的信息”。

## 本地数据

OPT 的项目状态、日志、记忆、配置和运行证据中，可能包含与你本机环境有关的信息。

不同功能可能会按你的配置与 GitHub、Runner 或其他外部工具交互。

Alpha 版本仍在快速迭代，因此请把本机中的项目配置、日志和支持包视为可能包含环境信息的材料，不要未经检查直接公开上传。

## GitHub Issues / Discussions 是公开的

本仓库是 Public。

你提交到以下位置的内容可能被任何人看到：

- Issues
- Discussions
- 评论
- 截图
- 附件

因此请不要公开提交：

- GitHub Token / API Key
- 密码
- Cookie / Session
- 私有仓库源码
- 私有仓库完整路径（如果你介意暴露）
- 公司内部信息
- 个人隐私数据
- 未经检查的完整日志或 Support Bundle

## 日志

Alpha 01 应用异常日志默认位置：

```text
%LOCALAPPDATA%\OPTAssetLite\logs\app.log
```

日志主要用于排查异常，但提交前请自行检查并删除不希望公开的信息。

## Support Bundle

如果产品提供 Bridge / Runner Support Bundle，请把它视为诊断材料。

在公开上传前应检查其中是否包含：

- 机器名
- 用户目录
- 仓库信息
- 路径
- 网络或 Runner 标识
- 其他你不希望公开的数据

如果不确定，请先在 Discussion 中描述现象，不要直接上传完整包。

## Alpha 阶段的数据原则

OPT 当前不会因为“方便调试”就要求用户默认公开自己的私有项目内容。

如果未来新增遥测、云同步、账号体系或远程诊断，我们会在启用之前补充相应说明，而不是默认把本地数据视为可上传。

## 安全问题

如果你发现可能影响密钥、权限、数据完整性或其他用户安全的问题，请不要先公开披露。

请先阅读 [SECURITY.md](../SECURITY.md)。
